# ระบบสะสมแต้ม ร้านเล็บเศรษฐี 💅

สะสมครบ 10 ครั้ง ฟรี 1 ครั้ง — ลงทะเบียนด้วยเบอร์โทร, ข้อมูลเก็บใน Google Sheets

| หน้า | ใช้งานโดย | ทำอะไรได้ |
|---|---|---|
| `index.html` | ลูกค้า | สมัครสมาชิก (เบอร์ + ชื่อ), ดูแต้มสะสม |
| `admin.html` | พนักงาน (ใช้ PIN) | ค้นหาลูกค้า, สมัครให้, +1 แต้ม, ใช้สิทธิ์ฟรี, −1 แต้ม (แก้ไขกรณีกดผิด) |

## ติดตั้งฝั่ง Google Sheets (ทำครั้งเดียว)

1. เปิด Google Sheet ของร้าน → เมนู **Extensions (ส่วนขยาย) → Apps Script**
2. ลบโค้ดเดิม แล้ววางโค้ดจากไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) → กดบันทึก
3. เลือกฟังก์ชัน `setup` ด้านบน → กด **Run** → อนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to project)
   - จะสร้างชีต `Members` และ `Log` ให้อัตโนมัติ และตั้ง PIN เริ่มต้นเป็น `1234`
4. เปลี่ยน PIN: แก้ตัวเลขในฟังก์ชัน `changePin` → เลือก `changePin` → กด **Run**
5. กด **Deploy → New deployment** → ไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
6. นำ URL ไปใส่ใน [`config.js`](config.js) ที่ `API_URL: '...'` แล้ว commit

> ถ้าแก้ไขโค้ดใน Apps Script ภายหลัง ต้อง **Deploy → Manage deployments → แก้ไข (ดินสอ) → Version: New version** ทุกครั้ง URL จะคงเดิม

## โหมดทดลอง

ถ้า `API_URL` ยังว่าง เว็บจะทำงานแบบทดลอง (เก็บข้อมูลในเบราว์เซอร์เท่านั้น, PIN = `1234`) มีแถบแจ้งเตือนด้านบน

## ข้อมูลใน Google Sheets

- **Members**: เบอร์โทร, ชื่อ, แต้มปัจจุบัน, มาใช้บริการทั้งหมด, ใช้สิทธิ์ฟรีไปแล้ว, วันที่สมัคร, มาล่าสุด
- **Log**: ประวัติทุกการทำรายการ (สมัคร / เพิ่มแต้ม / ลบแต้ม / ใช้สิทธิ์ฟรี)
